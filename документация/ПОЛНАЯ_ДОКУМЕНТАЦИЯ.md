# Полная документация системы "25 точек"

## Назначение

Автоматизация приёма и обработки заказов от 25 торговых точек через Telegram-бот с последующей отправкой поставщикам.

### Бизнес-процесс

1. Точка делает заказ через Telegram (голос/текст)
2. n8n обрабатывает и распознаёт заказ (Whisper + GPT-4)
3. Заказ попадает в дашборд к ответственному лицу
4. Ответственное лицо подтверждает/корректирует заказы
5. Система группирует заказы по поставщикам и типам товаров
6. Формируются Excel-файлы для каждого поставщика
7. Отправка поставщикам через Telegram или Email

## База данных

**Файл:** `/home/devartemiy/25tochek/Dashborad/app.db`
**Тип:** SQLite 3, UTF-8

### Таблица: points (торговые точки)

```sql
CREATE TABLE points (
    id INTEGER PRIMARY KEY,
    name TEXT,                      -- Название ("Мира 45")
    address TEXT,                   -- Адрес
    owner TEXT,                     -- Владелец (ИП Солдатов, ИП Афонин)
    idTg TEXT NOT NULL,             -- Telegram ID точки
    manager_telegram_id TEXT,       -- ID менеджера (через запятую)
    note TEXT,                      -- Примечание
    is_deleted BOOLEAN DEFAULT 0    -- Мягкое удаление
);
```

### Таблица: orders (заказы)

```sql
CREATE TABLE orders (
    id INTEGER PRIMARY KEY,
    point_id INTEGER,                        -- FK → points.id
    created_at DATETIME DEFAULT (datetime('now', '+3 hours')),
    status TEXT DEFAULT 'new',               -- new/confirmed/rejected
    tg_name TEXT DEFAULT '',
    tg_username TEXT DEFAULT '',
    sent_to_supplier BOOLEAN DEFAULT 0,
    is_closed BOOLEAN DEFAULT 0,
    FOREIGN KEY (point_id) REFERENCES points(id)
);
```

Статусы: `new` → `confirmed` → отправка | `rejected`
Ручные правки: `tg_username="dashboard_manual"`

### Таблица: order_items (позиции заказов)

```sql
CREATE TABLE order_items (
    id INTEGER PRIMARY KEY,
    order_id INTEGER NOT NULL,
    product_id INTEGER,
    suppliers_id INTEGER,
    type TEXT,                               -- Тип товара
    subtype TEXT,
    name TEXT,
    count REAL,
    is_sent_to_supplier BOOLEAN DEFAULT 0,
    is_sending_to_supplier BOOLEAN DEFAULT 0,
    FOREIGN KEY (order_id) REFERENCES orders(id),
    FOREIGN KEY (product_id) REFERENCES product(id),
    FOREIGN KEY (suppliers_id) REFERENCES suppliers(id)
);
```

### Таблица: product (товары)

```sql
CREATE TABLE product (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    unit TEXT,                    -- л, кг, шт
    product_type TEXT             -- для группировки
);
```

11 типов: Белизна, Вафельное полотно, Вода, Ирексол софт сдоба, Лимонады, Молочка, Мука/Сахар, Пищеснаб, Продукты, Сосиски, Упаковка

### Таблица: suppliers (поставщики)
