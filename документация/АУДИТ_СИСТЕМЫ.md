## Критические проблемы (исправлять первыми)

### 1. DB Session Leak — main.py (11 мест)
**Где:** Все `/export/*` endpoints (строки 2204-2979)
**Проблема:** `db = SessionLocal()` без `try/finally/db.close()` — утечка соединений к SQLite
**Влияние:** При частых экспортах — блокировка БД ("database is locked")

### 2. Telegram Bot Token в n8n workflow
**Где:** HTTP Request, HTTP Request1, HTTP Request2 в workflow 1
**Проблема:** Token `8277467815:AAHg...` захардкожен в URL вместо n8n credentials
**Влияние:** Компрометация бота при утечке JSON файла

### 3. XSS через innerHTML — frontend
**Где:** dashboard.html (38+ мест с innerHTML)
**Проблема:** Данные с сервера вставляются в DOM без экранирования
**Влияние:** Если в названии товара/точки будет `<script>` — выполнение произвольного кода

### 4. Потеря данных в HTTP Request нодах — n8n
**Где:** HTTP Request 3, 5, 6 в workflow 1
**Проблема:** HTTP Request нода заменяет весь `$json` ответом сервера (известная ловушка n8n)
**Влияние:** Данные из предыдущих нод теряются

### 5. Нет Error Handler — оба n8n workflow
**Где:** 0 из 64 нод имеют error handling
**Проблема:** Любая ошибка = workflow падает молча
**Влияние:** Потеря заказов без уведомления
